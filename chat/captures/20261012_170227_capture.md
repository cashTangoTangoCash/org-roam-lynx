let's add a key feature to the python script.  We see a list of org roam nodes (MAIN, BIDIR, OUT, IN).  We have a selection mark (highlight) that we move up and down.  Let's add one new action to apply to the org roam node at the selection mark.  When we press "i" key, emacsclient is used to insert an org mode link to the selected node at point in emacs (in whatever buffer is I guess visible in emacs - not sure of the right language here), followed by a space.  When we press "I" key, we similarly insert an org mode link followed by a newline.  The use case is adding links quickly: we can visit an org roam node in emacs, move point to where we desire to insert a link to a roam node, put selection mark on that roam node in our terminal application, and hit i or I to paste a link into emacs.  This can be a fast way to paste the same link multiple times in emacs, rather than calling org-roam-node-insert over and over (it seems to have some overhead).
